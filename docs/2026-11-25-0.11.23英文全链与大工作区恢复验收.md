# 0.11.23 英文全链与大工作区恢复验收

日期：2026-11-25。用户确认本轮补充英文缺陷、TARGET第三轮只先落地好评回调与无效评价，负向等待业务仲裁；并追加英文界面的模型返回内容也必须英文。以下为Codex实现/本机合成测试报告，不等同真实模型效果验收。

## 最终行为

- 英文静态文案、重复导入徽标、分页、规则出处、标准NP/EC名称内置对照；英文错误保留明确原因和操作指引，未知错误使用英文提示而不拼接中文。
- 英文AI理由、归类理由及辅助结果使用显示层翻译；等待/失败主展示只英文状态，原AI输出留审计原文区，不改写判定与原文。翻译后仍非英文不能仅因status=translated当作合格。用户源数据与证据原文保持原样。
- 英文报告与Excel的AI原因、摘要、点评与建议覆盖翻译；未译内容不作为英文正文回退，原文保留独立审计。首次翻译依赖本机配置模型，缓存切换即时，不重跑质检。
- EC-TARGET冻结ec-target-calibration-v3：好评回应具体夸赞点或有相关增量即可；完全无回应且无相关增量才不符合。无效评价单条语义针对性不适用，同管理员至少3条组内彼此85%的批次重复仍独立判。负向v2口径未改。
- 人工分类切入/切出无效时重新核对TARGET；能力恢复为无效时对未确认依赖项刷新，人工保护记录仅提示/候选，不静默覆盖。旧任务保持冻结版本，新包自动备份发布新配置仅影响新任务。
- 大工作区沿用按revision和内容哈希读取分片及Worker解析，按体积给30–180秒预算；活动快照不被其他标签页逐出，读取完成释放快照，并复用未变记录的分片缓存。相同JSON内容在不同逻辑字段独立，不引入数组/对象别名。首次加载失败退避重试并自动解锁；未知写入结果仍保持显式幂等重试/冲突恢复。
- 租约释放不改变工作区mutationEpoch，纯读取不再使已预检备份恢复误报版本冲突。
