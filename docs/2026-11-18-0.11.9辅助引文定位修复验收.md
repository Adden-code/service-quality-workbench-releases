# 0.11.9 辅助引文定位修复验收

日期：2026-11-18。范围：用户本轮需求五，以及恢复测试揭示的同链路持久化缺陷。全部测试输入为合成资料，未调用外部模型。内网真实批次未读取、未代跑。

## 需求与实现

| 项目 | 已实施内容 |
|---|---|
| 偏移类型 | 与confidence共用数值字符串归一化，后续严格要求安全整数、非负start、end大于start。空白、等级文本、布尔、null、十六进制、分数、越安全整数范围拒绝。 |
| 位置修复 | 规范偏移不能切出quote时，仅在指定block.text内做严格逐字搜索。唯一命中修复UTF16偏移；多处命中（含重叠）拒绝。原偏移已精确定位时保留原有行为，不重新猜测位置。 |
| 文本边界 | 不改写quote，不跨block，不折叠空白，不为这条修复引入Unicode宽容、阿语替换或模糊搜索。此前规则检核链路的规范等价逻辑不变。 |
| 留痕 | 每条修复证据保存locatorRepair：version、method、originalStart、originalEnd；quote仍为模型原始引文，start/end为程序验证的定位。模型schema仍要求JSON整数，不新增业务字段。 |
| 失败处理 | 重试提示明确confidence为JSON number、start/end为JSON整数；最终失败保留具体的类型/逐字不命中/多处命中说明。有限重试和熔断未停用。 |
| 恢复关联缺陷 | 分类从失败恢复后，存储校验原本用新分类重算旧EC-TIME，触发storage_error。现仅在恢复时冻结旧时效判断的分类输入judgmentClassificationSnapshot，后续重算/批次合并使用该旧输入。原AI结论、人工记录不改写；恢复分类与后续新行正常保存。快照生成必须与旧输入完全相同，生成后禁止改写。 |
